# Правила работы с публикацией Идеал Сервис

Этот репозиторий содержит опубликованную зашифрованную сборку, а не исходный код приложения.

- Перед изменениями приложения открыть закрытый репозиторий iamkurakov/ideal_potolok_data и прочитать его AGENTS.md, docs/ARCHITECTURE.md, docs/WORKFLOW.md.
- Если закрытый репозиторий недоступен, не восстанавливать приложение правками шифротекста.
- Изменять исходники в app/ закрытого репозитория, затем собирать через build.py --publish.
- Не редактировать зашифрованный index.html вручную.
- Публиковать только зашифрованный index.html и необходимые публичные ресурсы. Сохранять .nojekyll и документацию.
- Не размещать здесь открытый dist/index.html, исходники, секреты, заказы, настройки, внутренние прайсы и резервные копии.
- Перед коммитом проверить diff и отсутствие открытых секретов. Не использовать git add -A.
- Проверить развёртывание Pages после публикации; отличать сохранение исходников от обновления сайта.
- Для отката использовать целевой коммит публикации, без переписывания истории.
